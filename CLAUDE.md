## What this project is

An interactive web tool for analyzing ImmunityBio (IBRX) clinical trials. It has two pages:

- **Trading Timeline** (`index.html`) — a vis.js Timeline showing trials as bars from study start to primary completion date, with revenue overlay and tooltip overlays
- **Partner Drug/Pharma** (`cotreatment.html`) — two Chart.js doughnut charts (co-treatments and pharma partners) that cross-filter each other, plus a sortable trial table

Both pages load data from `csv/ibrx.csv` at runtime via `fetch()`.

## Refreshing the CSV data

The CSV is generated by the Python script. Run from the repo root:

```bash
cd "python " && python3 get_clinicaltrials.py
```

This fetches from the ClinicalTrials.gov v2 API and writes `csv/ibrx.csv` (plus a timestamped raw JSON file for debugging). No external dependencies — uses only stdlib. The script also accepts:

```bash
python3 get_clinicaltrials.py --nct-list NCT12345678,NCT87654321
python3 get_clinicaltrials.py --query "some search term"
python3 get_clinicaltrials.py --study-start-after 2019-01-01
```

## CSV schema

The CSV columns consumed by the HTML pages are:

| Column | Notes |
|---|---|
| `Indication` | Canonicalized disease name |
| `Category` | `Cancer`, `Virus`, or `Immunodeficiency` |
| `Link` | Full ClinicalTrials.gov URL |
| `Study start` | ISO date |
| `Primary completion` | ISO date |
| `Phase` | e.g. `P1; P2` |
| `IBRX drug` | Semicolon-separated IBRX interventions |
| `Co-treatments` | Semicolon-separated partner drugs |
| `Sponsor` | Lead sponsor name |
| `Platform` | Always `Immunocytokine` |
| `Co-treatment 3rd Parties` | Semicolon-separated pharma company names |

## Architecture: normalization dictionaries

The Python script contains several lookup dictionaries that map raw ClinicalTrials.gov strings to canonical display names. When the raw API data changes, or a new drug/indication needs to be handled, update these:

- `IBRX_NAMES_CSV` / `IBRX_KEYS` — determines whether an intervention is classified as an IBRX drug vs. a co-treatment
- `IBRX_DRUG_EXACT_MAP` — normalizes IBRX drug display names (e.g., N-803 → Anktiva)
- `PARTNER_DRUG_EXACT_MAP` — normalizes partner drug display names
- `PARTNER_PHARMA_EXACT_MAP` — maps partner drug names to their pharma company
- `canonicalize_indication()` — regex-based rules that collapse aliases into a single indication string

## Serving the pages locally

The pages use `fetch()` for the CSV, so they need a local HTTP server (not `file://`):

```bash
python3 -m http.server 8080
# then open http://localhost:8080/
```

Both HTML files are at the repo root, so serve from there.

## Revenue overlay

`js/time/revenue-overlay.js` draws an SVG line graph over the vis.js timeline canvas showing IBRX quarterly revenue. The `REVENUE_POINTS` array at the top of that file contains the hardcoded quarterly values in `$M` — update this array when new earnings are reported.
